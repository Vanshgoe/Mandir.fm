# ॐ Shanti

ॐ Shanti is a simple devotional music player website inspired by **saloon.wtf**.

The project creates a peaceful temple-like atmosphere where users can listen to bhajans and mantras with a minimal and calming interface.

## Features

- Devotional music player
- Play, pause, and next controls
- Temple background
- Live clock
- Location detection
- Responsive design

## Built With

- HTML
- CSS
- JavaScript

## Inspiration

Inspired by **saloon.wtf** — a simple website that creates an emotional experience through music and nostalgia.
